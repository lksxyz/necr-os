# Design

Follow the design direction in #[[file:DESIGN.md]] for every UI change: tokens, the memorial label motif, layout, the two-register voice (keeper and literal), terminology, and accessibility.

- Keeper lines come only from the table in DESIGN.md. Add a line there before using it in the UI.
- Controls, errors, states, and data stay literal. No theme words on buttons.
- No cartoon horror: no ghosts, skulls, bats, cobwebs, fog, or Halloween purple and green.

Run UI work through the antislop skills committed in `.kiro/skills/` (`antislop`, `antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`) and report their Delivery Gate. Light mode only. No em dashes in UI text.

Planned design work is tracked as a spec in `.kiro/specs/mourning-archive/`.
